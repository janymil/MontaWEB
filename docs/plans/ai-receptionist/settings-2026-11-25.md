# ElevenLabs agent settings (draft, set 2026-11-25, NOT published)

Agent "MontaWeb Recepcionista". Set as pending changes on branch Main; they take effect only after Publish (Jan's yes).

| Setting | Value | Why |
|---|---|---|
| Take turn after silence | 7 s (default kept) | Standard for phone calls; shorter cuts people off, longer feels dead |
| End conversation after silence | 30 s (was disabled) | Stops paid minutes on abandoned or muted calls |
| Max conversation duration | 600 s (default kept) | A qualify-and-book call is 3-6 min; caps cost ($0.08/min) and runaway calls |
| Store Call Audio | Off (was on) | Data minimisation (Ley 29733); the transcript is enough for review |
| Conversations retention | 90 days (was unlimited) | Enough to review and tune; not indefinite |
| Zero Retention Mode | Off | Would hide transcripts and make debugging impossible |
