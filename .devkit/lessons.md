# Lessons — this app

One line per surprise, newest first. Cheaper than rediscovering the same trap next month.

Format: `YYYY-MM-DD — what happened — what to do next time`

Delete a lesson only when the thing that caused it no longer exists.

---

- 2026-11-25 — archive.org answers a repeated Save Page Now with the earlier copy and HTTP 200; the script logged it as new, although it showed our page before the deploy. A snapshot only counts if its timestamp matches the request.
- 2026-11-25 — port 8781 was held by another worktree's server (404 on new pages), and the Chrome window would not shrink below desktop; serve this worktree on 8783 (`montaweb-static-8783`) and check 375 px in a same-origin 375 px iframe. Also: a stacked `.kw-table` needs `caption{display:block}` or the caption squeezes to one word per line.
- 2026-11-25 — evidence captures: headless Chrome's print CSS gave a near-empty PDF for hosting.com.pe (emulate `screen` media), our cookie notice covered table rows (second pass with it closed), and `process.exit()` right after `fetch` crashes Node on Windows with a libuv assertion (set `process.exitCode`). Look at the captures before sealing them.
- 2026-11-25 — four WordPress demos were taken over because sites exported from the Local app keep `admin` / `admin`; the attacker installed WP File Manager from wp-admin and uploaded webshells. Never ship a Local site without a new admin name and random password; build WordPress only with `scripts/wp-site-build.sh` (immutable image, `DISALLOW_FILE_MODS`, Caddy `wp_hardening`). Also: Caddy serves the whole checkout, so `/deploy` and `/.devkit` were public until the `@internal` matcher — add every new repo folder that is not site content to it.
- 2026-11-25 — first scripted deploy stopped because the server had uncommitted copies of files the commits added (demo sites); they were byte-identical (`git hash-object` vs `origin/main:<f>`), so they were backed up to `/var/www/montaweb-backup-*`, removed, and the pull finished. Check identity first, never stash or reset there.
- 2026-11-25 — deploy only via `scripts/deploy.sh` (`npm run deploy:status` / `npm run deploy`); it locks, shows what goes live, verifies the origin and logs. Never hand-run push + server pull.
- 2026-11-25 — the `montaweb-static` preview server from launch.json was not reachable at 127.0.0.1 from Claude in Chrome (connection refused); run `python -m http.server <port> --bind 127.0.0.1` in the background from the worktree and open that instead.
- 2026-11-25 — tests pinned exact `?v=` cache-bust strings, so every legitimate version bump broke them; they now match `\?v=\d{8}[a-z]?`. Also: the in-app Browser pane refuses localhost here and headless Chrome screenshots skip `.reveal-item` sections; check pages in Claude in Chrome at 127.0.0.1 instead.
- 2026-11-24 — research data under `docs/` was publicly downloadable because Caddy serves the whole checkout; `/docs` and `/scripts` are now 404 via the `@private` matcher in `/etc/caddy/Caddyfile` (backup `.bak-*`). Anything new under the web root is public unless that matcher covers it.
- 2026-11-24 — the 28 s 480×854 promo re-encoded *smaller* as H.264/MP4 (1.20 MB, CRF 26) than as VP9/WebM (1.44 MB, CRF 34), so "WebM is always the light one" is false at this size; encode both, measure, and keep `<source>` order WebM→MP4 for browser support rather than for bytes.
- 2026-11-24 — "deploy to washington" looks like `git push live`, but `/var/www/montaweb` is a non-bare checkout of `main` with `receive.denyCurrentBranch` unset and no hooks, and the local `live/main` ref is often stale; deploy by pushing `origin` and running `git pull --ff-only origin main` on the server, commit only the paths you mean (the server carries its own uncommitted demo-site work), then verify the origin with `curl --resolve` because Cloudflare rewrites the public body (email obfuscation, challenge script).
- 2026-11-24 — the VPS at 216.22.17.204 does not answer HTTPS from this workstation at all (curl times out), so origin checks must run *on* the server (`ssh washington "curl --resolve montaweb.pe:443:127.0.0.1 …"`); the public hostname still works for end-to-end checks.
- 2026-11-24 — the brief's debounced autosave could recreate a draft after success, and legacy dark-theme status text was faint on the new light cards; cancel pending saves before clearing storage and override feedback colors in `site.css`.
- 2026-11-23 — `clinica.html` and `restaurante.html` are immediate redirects, but the shared page test required a scroll button on them; detect redirect-only documents and verify their destination instead of forcing unused UI onto them.
- 2026-11-07 — "add a go-up button" was already built on every live page by `initBackToTop()` in `js/app.js`; the only pages without one were the three orphan Google guides. Grep for the behaviour before building it, not just for the markup.
- 2026-11-07 — every page pins `js/app.js?v=2026` and Caddy serves `/js/*` with a 24 h TTL, so a fixed script keeps being served from cache. Bump `?v=` whichever shared js/css file you touch. The `update-cache-version.py` the README mentions no longer exists.
- 2026-11-25: Local port 8765 belongs to another app (returns "Not Found" JSON); preview MontaWeb with the `montaweb-static-8781` launch config. Nubix (nubix.pe) animates prices from 0, so headless captures show "S/ 0": check `data-count` in the source and save a normal-browser screenshot.
